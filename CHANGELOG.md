## 1.1.0

- Added an **Add to FavFiles** command available from the Explorer context menu, the editor context menu, the editor title bar, and the tab context menu, so the active file can be favorited from anywhere without leaving the editor.
- Added drag and drop into the FavFiles tree: files and folders can be dropped from the Explorer, and editor tabs can be dragged and dropped, to add them as favorites instantly.
- Reworked drag-and-drop handling to support external drops (Explorer and editor tabs) in addition to reordering and moving items within the tree, with clearer warning feedback when a drop is not allowed.
- Groups can now be nested, and the group selection quick pick shows nested groups with indentation and their resource paths.
